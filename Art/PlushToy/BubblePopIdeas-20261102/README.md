## 要解决什么

《泡泡小队》里，毛绒玩具队员吹泡泡，打掉上方泡泡阵里同色的小泡泡。我们想让**"打中、泡泡破掉"这一下非常爽**：

- 有"泡泡破了、水花四溅"的感觉，要湿润、透亮、有弹性；不要像实心珠子碎掉，也不要像冲击波、气浪。
- **热闹**：连打的时候，一串串破裂此起彼伏，有节奏感、有满足感，像捏泡泡纸一样上瘾。
- 一眼看得出**是什么颜色的泡泡破了**：泡泡阵里有十几种颜色。

我们试过几版程序画的效果，都不够好：

- `references/program-pop-problem.png`：一圈圈的弧线和圆圈，用户觉得"像鬼一样"、不好看。
- `references/current-splash.png`：现在临时用的版本，把已有的水花序列帧染成泡泡颜色。方向接近了，但不够热闹，也不够有设计感。

## 游戏里的情况（供参考，不是限制）

- 画风：圆润、亮色、轻 3D、毛绒和肥皂泡的世界。现有的特效可以参考 `references/style-rocket-pop.png`（泡泡爆点）和 `references/style-impact-dust.png`（水花）。
- 被打的泡泡在屏幕上很小，直径约 11 像素；破裂效果可以比它大很多，30～100 像素都可以，你来判断。
- 破得很频繁：同一秒里屏幕上可能有十几到几十个破裂同时在播，所以单个效果不能太长，0.2～0.4 秒左右；密集时不能糊成一片白雾。
- 程序可以给图染色、缩放、旋转、调透明度、按帧播放，也可以把一个效果拆成几层组合（例如一层随泡泡颜色染色，一层保持白色高光）。
- 连击越高，效果可以越大、越华丽，这个可以纳入你的设计。

## 想看到什么

请设计 **3～4 版方向明显不同的方案**。方向举几个例子，可以不按这个来：

- 透明肥皂泡啪地破开，溅出一圈水珠和泡沫
- 果冻、水球那种 Q 弹地挤扁再炸开
- 卡通漫画式的"啵！"，带简洁的形状和小星星
- 泡泡破后变成几颗更小的泡泡飘散
- 你觉得更有意思的方向

每版请交：

- 一张**逐帧图**：4～6 帧横排，透明底，每帧 256×256 左右；
- 一个**连播 GIF**：叠在 `references/` 里的泡泡阵截图上，单个破裂和一排连打各一段；
- 一两句**设计说明**：这版想要的感觉、为什么热闹、怎么体现泡泡颜色。

请把**至少一版**画成能被程序染色的形式（白到灰的颜色层，加上白色高光层），方便直接进游戏试；其他几版可以自由发挥，不用考虑染色。
