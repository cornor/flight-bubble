- 标题从小到大弹出。
- 两支箭头放在标题两端上方，从下往上冲到位，然后轻微上下浮动。
- 光带贴着泡泡阵下沿，跟着泡泡上推一起往上走，并且左右缓慢流动。
- 星光在标题四周随机闪烁。
- 全部效果在托盘内，1.5 秒后淡出。
