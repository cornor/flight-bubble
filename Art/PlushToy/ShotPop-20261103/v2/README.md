# 第二版：去掉持续的「du du du」音调

2026-11-03，用户试听第一版后反馈：「du du du 的那个声音不好」。本版去掉开火和消除中的持续纯音主体，改用短气流和宽频破裂声。第一版文件保留；仍然只做独立试听，没有替换游戏资源、修改游戏代码、构建或发布。

## 先听这一段

`previews/01-v2-separated-demo.mp3`，共 12 秒，没有背景音乐：

- 0–3 秒：第二版开火，8 个变体依次播放。
- 3–6 秒：第二版消除，8 个变体依次播放。
- 6–12 秒：第二版开火与消除一起连续播放。

## 变化

- 第一版开火主体最终落在约 390 Hz，消除主体落在约 810 Hz，另有约 420 Hz 的空腔声。持续重复这类纯音容易形成明显音调。本版两类声音均移除这些正弦波与音高滑动。
- 开火：40–48 毫秒，以短气流为主，加入一次很短的压缩/释压波形。没有循环振荡器。
- 消除：43–51 毫秒，以宽频膜片破裂和很短的起音构成；软饱和控制瞬时尖峰。没有带音高的尾巴。
- 8 个变体主要改变噪声细节、长度、衰减和频带，避免依靠音高变化变成一串音符。
- 每个新素材的总音频能量与第一版相应素材匹配。不同频谱仍可能有不同的主观响度，不把能量相同当作人耳听感完全相同。

## 文件与检查

- `masters/`：16 个 44.1 kHz、单声道、24-bit PCM WAV。
- `delivery/shot/`、`delivery/hit/`：各 8 个 44.1 kHz、单声道、16-bit PCM WAV。
- `manifest.json`：参数、时长、峰值、RMS、相对第一版能量、文件哈希、MP3 解码检查。
- `timelines.json`：分段和连续攻击的逐事件时间、音量、音高与变体。
- `make_trial_v2.py`：可复现脚本，复用上一级 `make_trial.py` 的文件读写和试听节奏函数，只写本目录。需要 Python 3、numpy、ffmpeg。

频谱检查用最强连续 100 Hz 频带占 120–8000 Hz 总能量的比例，作为持续音调集中的粗略指标；它不是听感评分。第二版两类声音的该比例均明显低于第一版，具体值保存在 manifest。

16 个变体互不相同，主文件首尾为零；交付格式、音量匹配和导出后削波已检查。生成前后对比哈希，游戏当前开火/消除/音乐、第一版交付和第一版脚本均未改变。所有试听共用总增益，没有分别归一化新旧片段。

这里只完成技术检查，是否更符合期待仍以用户试听为准，尚未做手机扬声器或微信游戏内播放验证。
