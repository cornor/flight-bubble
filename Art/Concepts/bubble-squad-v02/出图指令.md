## 1. v01 评审结论（本版必须改）

| # | v01 的问题 | v02 的要求 |
| --- | --- | --- |
| 1 | 队列每条只画一种颜色，看起来已经分好类 | 队列按第 3 节给的颜色混排，同一条跑道里至少两种颜色 |
| 2 | 队列只在管子底部画一个数字 | **每个单位脚下各有自己的数字**，出战位和队列都一样 |
| 3 | 泡泡阵约 45–50 列，泡泡画大了 | 按真实比例：**60 列**，泡泡是排得规整的小圆珠，横向之间有细缝；以参考图的密度为准 |
| 4 | 吐出的泡泡、飞着的泡泡、掉落的泡泡长得一样，崩塌区看不清 | 三种东西用三种形态（第 2 节"三种泡泡"） |
| 5 | 合体后只大一点点，而且第一次合成就标 MAX | 合体后身体约 1.35 倍、多一个特征（头顶多一撮泡沫），脚下标 **Ⅰ**；MAX 只用于最高级，本版不出现 |
| 6 | 7 个出战位 | 这三关都是 **8 个出战位：前 6 个可用，后 2 个锁定**（锁头图标） |
| 7 | 泡泡生物为什么要打泡泡画，没有交代 | 泡泡阵的上沿挂在一条**厚厚的泡沫云顶棚**下，像经典泡泡游戏那样整片往下压；第 3 张的图案本身就是一个"敌人"（委屈幽灵） |

### 2.2 三种泡泡（必须一眼分清）

| 东西 | 画法 |
| --- | --- |
| **目标泡泡**（泡泡阵） | 不透明实色小圆珠，左上一个小白高光，下半略深；60 列规整网格，横向有细缝 |
| **弹体**（角色吐出的） | 半透明的肥皂泡，比目标泡泡还小，带一条同色短拖尾，排成一串；能看出是"空心的"，和实心目标泡泡不同 |
| **掉落的泡泡** | 和目标泡泡一模一样（实色、同大小），只是脱离网格往下掉，身后有两三道浅色速度线；不旋转、不加星星 |
| 命中 | 只在命中点有一个小同色圆环炸开 |

| 橙 #FF7E27 | 梨形，两个短圆角，坏笑 | v01 | 和杏色比：有角、颜色更浓 |

### 2.4 数字

- 出战位：角色脚下一块深色圆角小牌，白色数字。
- 队列：每个角色正下方一个小数字，白字深描边；最前排的角色比后两排大约 1.1 倍。

## 4. 自查清单（每张逐项写结果）

1. 版式：各区域位置和第 2.1 节的百分比相差不超过 2%；**8 个出战位，后 2 个锁定**；4 条队列、每条 3 个。
2. 泡泡阵：数一行，**55–60 列**算通过；规整网格、横向有细缝；图案形状和颜色与参考图一致。
3. 数字：出战位每个角色一个数字，队列每个角色一个数字，和场景部分写的一致。
4. 队列混色：和场景部分写的颜色顺序一致。
5. 三种泡泡：弹体是半透明空心的小泡泡，掉落的是实心原大小，两者一眼分得开。
6. 同色：每个角色的身体、弹体、它打中的泡泡是同一颜色。用脚本在角色身体、泡泡阵对应颜色区域各取样，ΔE76 ≤ 15 记"通过"（概念图标准，生产图仍是 ≤ 8），把取样值写进记录。
7. 相近色：蓝/天蓝、橙/杏、白/薄荷/淡薰衣草、深灰/棕，在缩到 540×960 后靠轮廓特征仍能分清。
8. 场景三：合体角色明显比别的大（约 1.35 倍），脚下是 Ⅰ，没有 MAX。
9. 没有植物、花盆、篱笆、恐龙、战机，没有任何已有游戏的角色和标志；中文字清楚。
