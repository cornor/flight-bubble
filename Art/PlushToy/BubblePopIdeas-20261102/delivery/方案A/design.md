# 剪水啪 · Pinch Jet

膜先在命中点收紧，随即朝两端甩出一长一短的细水舌，断成沿斜线飞走的亮水滴。连打时水舌错开方向，水体跟随命中泡泡的颜色，尖端的白亮反光让深色水滴也看得清。

[六帧逐帧图](frames.png) · [单发及连打 GIF](preview.gif)

| 试播参数 | 数值 |
| --- | --- |
| 格子 | 横向 6 格，每格 256×256，锚点 (128, 128) |
| 各帧时长 | 20、40、40、40、60、60 ms，共 0.26 秒 |
| 下层 | [灰度水体](tint-body.png)，RGB 乘以命中泡泡色，保留原 alpha |
| 上层 | [白色高光](white-highlights.png)，同格同锚点，用普通透明混合叠放 |
| 示例色 | RGB (19, 156, 245)，见逐帧图 |
