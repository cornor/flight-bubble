1. **空主页**：用本包装的背景和按钮风格，只有「开始」和「设置」两个按钮。
2. **关卡**：全部 262 关（教学 2 关 + 正式 260 关）。战斗逻辑、数值、关卡数据、教学、道具（重排 / 优先出战 / 泡泡炸弹）、复活、广告、"全歼"终结演出、结算全部和来源一致。
