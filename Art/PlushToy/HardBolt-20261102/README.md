# 超难关卡开场：闪电序列帧

2026-11-02 10:25，用户反馈超难关卡开场"闪电有点假"，并确认改为美术画闪电序列帧（方案 A）。

现在的闪电是程序画的：一根白芯加一圈紫光，规整的五段折线，粗细一样，一直挂在两边闪，看起来像贴纸。改成美术画几张形状不同的闪电，由程序快速轮播，像真的在噼啪放电。

用在哪里：超难关卡开场，字标"超难关卡"两侧各劈下一道闪电，见 `references/opening-mock.png` 右边那张。字标、双箭头、紫色背光都已经有了，这次**只画闪电**。

参考图在 `references/`：

- `opening-mock.png`：三档开场对比示意，右边是超难关卡，**闪电的位置和大小以它为准**；示意里的闪电是程序画的，正是要替换的那种假闪电。
- `shahua-lightning-frames.png`：沙画同款动效的图集，里面那几张白色闪电（中间和右侧的白色折线）就是它的序列帧，**只参考"拆成几张、每张形状不同"的做法和闪电的质感**，造型不要照抄。

| B1–B6 | `delivery/bolt-1.png` … `delivery/bolt-6.png` | 各 256×512，透明 | 6 张竖向闪电，从画布顶部劈到底部。每张都是**白色闪电芯**：主干折线有自然的粗细变化，上粗下细，转折处尖锐；带两三根细分叉，分叉越往外越细、越淡；外面一圈很窄的白色柔光。六张形状各不相同（主干走向、分叉位置都要变），连着快速播放时像在噼啪闪动；但整体都在画布中间一条竖带里，不要一张偏左、一张偏右 |

要求：

- **只画白色**，不要上紫色。颜色由程序叠：超难是紫色光晕，以后其他地方也可能叠别的颜色。
- 不画背景、星星、火花。
- 画风偏卡通、干净，跟游戏整体的圆润亮色风格协调，不要写实照片质感，也不要太细碎。
- 透明边缘干净，四周不留白边，闪电顶端和底端可以贴到画布边缘。

程序这边的用法：

- 两侧各一道，右侧水平翻转使用。
- 每秒约 15 帧轮播。每轮劈两下，然后停一会儿再劈。
- 背后叠一层放大、染成紫色的同一张图做光晕，劈下的瞬间整屏轻轻闪一下紫光。
