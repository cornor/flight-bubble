# 关卡第二套：出图提示词

> 供出图的人或 AI 直接使用。计划见 `docs/r1/关卡第二套-实施计划.md`，工具见 `scripts/levels_b/README.md`。

## 出图规则（每批通用）

1. **数量**：每关独立生成 **4 张**候选。
2. **存放**：保存到 `Art/levels-b/source/`，文件名用「第N关-题材-01.png」…「-04.png」（N 是游戏关号）。
   - 原图按字节保存，不缩放、不调色、不修像素。尺寸不限（上一批是 1254×1254），工具会自己缩放。
3. **记录**（建议，与第一批一致）：
   - 实际提示词、文件名、尺寸、SHA-256 写进 `generation-日期.json`；
   - 一句交接说明写进 `handoff-日期.txt`。
4. **只出图**：不要运行 `convert.py`、不要写制作清单 `Art/levels-b/manifest.json`、不要评估或发布。这些由转换环节统一做。
5. **颜色只能用每关给定的色值**，比例按提示词里的约数，尽量接近。
   - 最大的那种颜色通常做背景，但以每关题材文档的方案为准（例如第 10 关白色主要是蛋壳、第 22 关绿色做远景）；背景也是要打掉的泡泡，不是空白。
   - 少量颜色（≤2%）要画成明确的小部件，比如眼睛、脸颊、小球，不要省略。
   - 转换工具能自动缩放、平移、翻转主体来凑比例，但**画不出来的颜色补不出来**。第一批乌龟就是红色太少，被判超限。

6. **位置要求**（2026-10-19 起）：每关的颜色有上下位置要求（原关颜色在哪个高度，B 关也要在差不多的高度，难度才接近）。提示词里用「从画面底边往上，占画面高度的百分之几」来描述，底边就是游戏里护栏的一侧。请尽量照做；转换工具只能小幅缩放、平移（约 ±5%），挪不动整块颜色。
7. **题材依据**：每关题材、颜色用途和位置要求的完整说明在 `docs/r1/关卡第二套-题材.md`「每关明细」。

## 公共前缀（每段提示词前都加上）

```
像素画，大颗粒像素风格（整幅画大约 60×60 个像素点），纯色平涂，不要渐变、不要抗锯齿，不要自动加阴影（需要的影子按指定颜色平涂），正方形构图，主体和各部分的上下位置严格按下面写的位置要求摆放（不要默认居中）。
背景干净无杂物，无文字、无边框、无水印。
```
