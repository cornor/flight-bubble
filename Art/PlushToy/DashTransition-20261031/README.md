要求：

- 手和腿在关节端（肩膀、胯）要画圆、画完整。程序会让它们绕关节转动 ±40°，转起来不能露出断口或缝。
- 手和腿要藏在身体后面一点：身体压住关节端。
- 画风、毛绒质感、光照和主页的啵啵一致：柔和的右上方光，圆润 3D。
- 不画任何特效：速度线、尘土、星星、背景都由程序画。

## 关节点：`delivery/parts.json`

记录每个零件的转动中心（画布像素，从左上角量），格式：

```json
{
  "arm-l": [150, 300],
  "arm-r": [362, 300],
  "leg-l": [210, 455],
  "leg-r": [302, 455],
  "mouth": [256, 250]
}
```

上面的数字只是示例，请按实际画的位置量：

- `arm-*` 是肩膀的转动中心
- `leg-*` 是胯的转动中心
- `mouth` 是嘴的中心
