## 2. 给程序：改动

### 2.1 胶囊（`GlassCapsule`）

- 正常路径使用玻璃切图，禁止再用逐行渐变和圆环线条代替底框。固定两端、仅横拉中间，圆头、高光和白色内边均来自素材；程序画框仅作缺资源兜底。
- 颜色（边框；文字多数深蓝 `#163E6D`）：

  | 类别 | 边框 | 用于 |
  |---|---|---|
  | 指引 | 天蓝 `#4CB8F0` | 01、02、03、07、10、16、27、29 |
  | 警告 | 珊瑚 `#F08A6C` | 04、06、17 |
  | 暂停 | 冰青 `#4FD8EE` | 05 |
  | 失败 | 琥珀 `#F5B731` | 18、19、20、26 |
  | 成功 | 薄荷 `#4FD6A0` | 13、14、15、25 |
  | 庆祝 | 金 `#F7C23A` | 11、22 |
  | 困难 | 金边、棕字 `#7A4A00` | 08 |
  | 超难 / 高连击 | 紫 `#A660F0`，深紫字 | 09、23 |

- 宽度按文字长度算（现在 toast 已经这样）。

### 2.2 图标

- 单行条图标的**可见内容**约为条高 86%；先扣除 PNG 透明留白再居中缩放。双行警告图标为条高 82%，第二行炸弹单独排版。
- 图标进图集后按 `ui/bar-icon-*` 取用；缺图时退回现在的画法。

### 2.3 装饰小泡泡（程序画）

- **样式**：透明玻璃泡，只有白色高光和淡边，不透明度 30–40%，颜色跟随边框；直径约条高 15–20%。
- **位置**：骑在边框线上，在右上角、左下角、右端三处里选一处；按文字内容固定选择（同一句每次同一处）；偶尔一大一小两颗。
- **数量**：

  | 类型 | 装饰泡泡 |
  |---|---|
  | 短消息（13–20、26） | 不加 |
  | 持续提示（01–03、05、07–11、27、29） | 最多 1 颗 |
  | 警告（04、06、17） | 不加 |
  | 庆祝（22、23、25、31–34） | 2–3 颗 |

- **动效**：提示条弹出时泡泡从边框冒出，轻轻上浮后停住。

### 2.4 文字与逐条改动

- 提示条使用独立的寒蝉全圆体 Bold 字形图集，绘制与测宽使用同一份字形指标；不替换其他页面字体。长文案在内边距内自动缩小。

## 10. 品质调整（2026-10-21）

### 10.1 风格规则（用户确认）

- **玻璃 = 信息**：提示条、标签、对话框、顶部信息、连击、里程碑——只看不点的，用浅色玻璃。
- **果冻 = 能点**：道具按钮、决战按钮、暂停、弹窗主按钮——要点的，保留饱满果冻质感。
- 两种质感之间统一：同一种圆体字、同样的白色高光位置（左上）、同一套色板（按钮蓝 = 提示天蓝的深一档）。
- 字号收成 4 档：标题 26–30、提示 18–20、正文 16、标签 14（最小）。
