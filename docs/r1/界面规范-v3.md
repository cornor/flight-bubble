## 1. 原则

1. **外观照示意图**：云端泡泡世界，干净的彩色描边、柔和赛璐璐明暗、明亮高光；界面是圆润的胶囊和玻璃质感。
2. **逻辑坐标不动**：泡泡位置、防线 y=562、出战位横向中心、跑道范围、点击 ID 和条件全部沿用 v2 第 2 节。
3. **示意图与规范不一致时以规范为准**：泡泡阵按 60 列真实间距程序绘制；位置按本规范第 3 节；弹体是空心半透明小泡。
4. **泡泡阵不加底板**：直接用背景天空（第 2 节，2026-10-15 用户决定）。

## 2. 泡泡阵底色：不加底板，直接用背景天空（2026-10-15 用户决定）

最初按颜色校验在泡泡阵下面加了一块中灰蓝 #8C919C 底板（全部 22 个关卡色值在正常、绿弱、红弱下最小色差 17.5），实机里占半屏、画面沉闷。用户决定**不要灰底**，泡泡阵直接画在背景天空上，和示意图一致。

- 泡泡阵区域背景是交付背景图里的天空（上 #60B1FD 到下 #94D2FE），程序不再画底板。
- **已知风险**：天空和教学关浅蓝 #42A9FF 的色差只有 2.8，和天蓝 #46D9FF 只有 9.7；色弱模拟下淡紫、天蓝也很近。靠泡泡的同色加深描边和高光区分轮廓，对照图上教学关的蓝色图案仍可读，但对比度较低。完整包验收时在手机上重点看教学关 1、2 和含天蓝、淡紫的关卡。
- 其他方案的对照：`Art/R1/art-v3/color-check/底色方案对照.png`（天空直接做底 / 天空加半透明白雾 / 浅灰紫 #BAB7C7 / 原灰底）。白雾会吃掉白色泡泡，浅灰紫仍偏灰。原灰底的计算保留在同目录（`bg_pick.py`、`bg_search.py`、`底色对照.png`）。

## 4. 元素要点

### 4.1 泡泡（程序绘制）

- 主色实心圆珠，统一左上光源：球面明暗、较小的椭圆高光、柔和亮区、右下渐暗和一小段弱反光；轮廓只保留一道，**不加脚、整圈光晕或透明球心**。
  - 2026-10-20 用户确认 B 版质感并要求接入。由 `scripts/r1v3/bead_material.py` 生成 48×48 母纹理，正式关预滤波为 12×12，教学关为 21×21；保留“可着色主体＋固定高光”两层绘制，不新增实时光照或绘制层。正式关四种贴图与确认预览的 B 版逐像素一致。
- 显示直径：正式关 **7.6**，教学关 **15.4**，比纵向行距（6.55 / 13.8）略大，下排压住上排一点，像堆起来的泡泡；按行序绘制，下排在上层。只改显示，泡泡位置和判定不变。
  - 过程：中间包第一版沿用 v2 的 5.5，泡泡间露出大片底色、发闷 → 放大到 6.4（上下刚好不碰）→ 去掉灰底后，泡泡缝里露出带渐变和云的天空，显得"糊" → 放大到 7.6 略叠压。对照：`Art/R1/art-v3/color-check/泡泡大小与背景对照.png`（泡泡大小 × 背景图 / 纯色天空），放大泡泡的作用远大于换纯色天空。
- 白色泡泡描边用冷灰 #8C96A2；深灰泡泡描边用浅灰 #969AA0。
- 教学关圆珠中心加白色小记号，帮助色弱玩家区分四色：蓝 圆点、橙 三角、绿 方块、紫 十字。"新队员加入"卡片上同一角色旁边也显示这个记号。
- 掉落的泡泡和阵里的泡泡同色同大，只是脱离网格往下掉，不旋转、不加星星。

### 4.2 角色

- 一种颜色一只泡泡生物，造型见 v3 计划第 3 节。三态沿用 v2 的映射：待战 idle、出手 attack、打完 spent（数字为 0）。
- 画布 224×256，透明底，**脚底在 y = 212、水平居中**，身体高 120–150、宽不超过 180；下方 44 像素留空（程序在那里画数字牌）。程序按这个定位。
- 合成等级放大：每级 × 1.06（v2 是 1.045），MAX 约 1.18 倍；8 格时边缘可以和邻位略有重叠，数字牌不能被挡。
- 队列数字（2026-10-15 20:52，照示意图）：和出战位一样放在深海军蓝胶囊底上，字号 12；队列里不显示等级金币。
- 动效（2026-10-15，只用 UI 时间和现有状态，不改射击时机）：
  - **待机呼吸**：出战位角色纵向 ±3.5%、横向反向收放，约 1.6 秒一个周期，每只角色相位错开；队列前排 ±3%、后排 ±2%。
  - **吐泡**：每次真实出手后 0.18 秒内先压扁（高 −16%、宽 +12%）再弹回；脚底不动。
  - **打完**：只保留慢慢的轻微起伏。
  - **眨眼**（2026-10-15）：待战角色每 3.1–5 秒眨一次，闭眼帧显示约 0.13 秒，每只角色错开。用美术第 58 项 `blink.png`；没交付时不眨。
  - **欢呼**（2026-10-15）：过关（Won）后全体换成第 59 项 `cheer.png`，呼吸幅度 ×2.2、频率加快，像一起蹦跳；没交付时只加大呼吸。
  - 已有的位移动画（上场、合体飞行、冲锋、泡泡下落）沿用原版事件和计时。

### 4.3 空出战位：金色漩涡（2026-10-15 用户指定保留）

- 参考：`Art/Concepts/bubble-squad-v02/reference/empty-pad-swirl.png`（截自 `03-ghost-merge-attempt-02.png`）。
- 显示条件：出战位已解锁且没有角色（开局空位、合体后空出的位置都算）。锁定位不显示。取代 v2 的小芽。
- 美术交一张**正俯视、圆形**的金色漩涡图（`ui/pad-swirl`，160×160，中心最亮、向外淡出、带几颗光点）。
- 程序绘制：先绕中心旋转（约 4 秒一圈），再纵向压扁到 0.45，让它平躺在台面上；宽度为台面宽的 0.95；亮度在 0.7–1.0 之间呼吸（2 秒一个周期）。美术交付的漩涡图很淡（平均不透明度约 7%），程序叠画两次。统一金色，合体后不改色（2026-10-15 决定）。
- 只读"已解锁且为空"这一现有状态，不改点击区域。
