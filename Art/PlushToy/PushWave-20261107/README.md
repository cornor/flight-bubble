位置约定（三张必须一致，程序按这个摆放和横向流动）：

- 浪顶泡沫线大致在画布 **y = 40** 这一行（卷浪可以上下起伏 ±15）；y = 20 以上只允许零星小泡。
- 浪身从泡沫线往下渐隐，到 y = 180 完全透明。
- **左右两端必须能无缝拼接**（最左一列和最右一列接得上），程序会把两张并排、横向缓慢滚动。

要求：

- **画成水，不要画成云或雾。** 浪身是半透明的浅青蓝（约 `#BFE8FF` 一带，越往下越透明），浪顶泡沫是干净的白色，带一点亮面高光；可以有淡淡的彩虹反光呼应肥皂泡。
- **浪头大小、高低要错落**，一整条里不要出现明显重复的同一个卷浪；整体节奏柔和。
- **淡、不抢眼：** 图本身按正常饱和度画，程序会以大约一半的不透明度叠上去；但不要大面积纯白或高对比的块面，叠在蓝、橙、白泡泡和浅蓝托盘底 `#B5D2F9` 上时，泡泡要能透出来。
- 边缘干净，跟游戏整体一致：圆润、亮色、轻 3D；不要写实的海浪、水花或烟雾。
- 透明边缘干净，上下不留白边；左右因为要拼接，内容可以一直画到边。

程序这边的用法（代码已写好，图交付后重新打图集即可生效）：

- 合成时，浪顶从泡泡阵最下面一颗泡泡的位置开始，先快后慢地往上推约 40 像素（连续合成时推得更高、更亮），0.7 秒内淡完。
- 两张并排，横向缓慢滚动；按 W1→W2→W3 交叉淡入淡出。
- 同时合成那一列的泡泡阵下沿被顶一下再回弹（程序已有）。
- 整体不透明度约 0.4–0.6。
