# 关卡第二套 · 出图简版（2026-10-26 起）

> **10-27 更新：** 用户确认沙流补偿后，颜色面积基本自由，只剩"原关数量很少的颜色在画面里也只能是小点缀"一条面积约束。下方新增第 19、31 关重画要求（按新规则生成）；其余关的旧要求仍可用，面积一项按新规则理解。


## 为什么可以简化

10-26 起难度由游戏自身战斗代码的无界面模拟判断，并可自动微调排队对齐原关；用户 23:31 确认"下 10/20 排比例"不再作为门槛、允许换色。出图只需守两条：

1. **颜色种数和大致面积**：画面用的颜色种数与原关棋盘相同，各色面积大致接近（程序补齐到精确格数；差得越多，补齐改动越大，图越容易被改坏）。
2. **颜色从可选范围里挑**：到本关为止已登场的角色颜色都能用；本关新登场角色若在原关棋盘上，必须出现在画面里。

不再需要：底部构图要求、各部位离边距离、"增加 N 格"之类的精确修改。图先求好看，再交给程序转换、算难度、调排队。

## 流程

1. 按下方要求每关出 2–3 张图（原图按字节存入 `Art/levels-b/source/`，命名照旧 `第N关-题材-编号.png`）。
2. `python3 scripts/levels_b/convert.py --level N --image 图 --recolor`（换色模式；只用原关颜色时可不加）。
3. `python3 scripts/levels_b/tune_queue.py --level N`（反复运行到结束）→ `--validate` → 达标则 `--apply`。
4. `structure.py N`、`evaluate.py N --headless` 记录检查，进入集中试玩。
5. 每关出图要求可随时用 `python3 scripts/levels_b/brief.py N` 重新生成。
