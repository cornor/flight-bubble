## 约束

- 受保护文件一个字节都不改（`scripts/protected-files.sha256`）。决战、火箭、援军的原绘制在 `Game/PixelWingGame.Finale*.cs`、`GiantPlane.cs`、`FanLaser.cs`、`Feedback/**` 里，都受保护。**做法是在 Garden 层新写绘制，只读原记录，并在 `PixelWingGame.Garden.cs` 里换掉原来的调用**，和第 5 步复用原 Feedback 记录的方式一样。
- **原绘制函数里有状态副作用，不能直接不调**：
  - `DrawFinaleButton`：写 `finaleReadyAt`、`finaleLanded`，播放 `finale-ready` 和 `land` 音效，调用 `feedback.Kick`，注册点击区 `HitBox(8, 100, 716, 340, 86)`；
  - `DrawFinale`：`finaleEndClock < 0 && ActiveFinale == null` 时把它记成 `ui`，收尾淡出要靠它；
  - `DrawFinaleGuide`：教学对话和状态。
  
  首选做法：照常调用原函数，但给 `PixelSurface` 加一个只在 Garden 层打开的"静音"开关（`Rendering/` 不在保护清单里），开着时跳过画图、保留点击区登记，然后画泡泡版。动手前先确认 `HitBox` 在静音时仍能正确登记（它会读 `gardenOverlay`）。做不到就把这些副作用逐条搬到新绘制里，并写进执行记录。
- 决战按钮的点击区域和输入 ID（BattleInput case 8）不变；新按钮按原尺寸 340×86（逻辑）、原中心 (270, 759) 来画。
