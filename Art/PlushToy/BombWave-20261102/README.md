程序试做的效果在 `references/program-wave-attempt.png`：只是一个干净的白圈在放大，没有空气被推开的扭曲感、厚度和层次。这次要的是"有品质的气浪"。

要求：

- 以白色为主，可以带淡淡的彩虹反光（和肥皂泡呼应），不要大面积的颜色；会叠在各种颜色的泡泡阵上。
- 圆环中间要透明，不要糊成一整块白，不能把整个泡泡阵盖住。
- 四张的环在画布上大小一样，放大由程序做；四张之间的变化是"厚亮 → 薄 → 散开 → 消散"。
- 透明边缘干净，四周不留白边。
- 画风干净、圆润、亮色，跟游戏整体一致，不要写实的爆炸烟尘或火焰。

程序这边的用法：

- 炸弹爆开的瞬间，从爆点开始，0.6 秒内从很小放大到约爆炸范围的 1.3 倍，同时按 W1→W4 切换并淡出。
- 和现有的彩虹泡泡破开、泡泡阵抖动、连锁破裂一起播。
