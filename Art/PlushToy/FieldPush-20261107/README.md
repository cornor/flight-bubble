位置约定（四张必须一致，程序按这个摆放）：

- 光带两端的最低处在画布 **y = 150** 这一行；中间拱起的最高处在 P1 约 y = 70，往后逐张变缓（P4 约 y = 120）。
- 光带水平居中，拱起的最高点在画布正中 x = 540。
- y = 150 以下只允许有很淡的光晕，不要画实体内容。

要求：

- 以白色和浅青蓝为主（白芯 + 约 `#BFE8FF` 的光晕），可以带一点淡淡的彩虹反光呼应肥皂泡；不要金色、不要大面积颜色。
- 会叠在蓝、橙、白等各种颜色的泡泡上，也会叠在浅蓝托盘底 `#B5D2F9` 上，两种底上都要看得清，但不能糊成一片把泡泡盖住。
- 程序会把图横向压到 0.55 倍再拉回 1 倍，所以不要画有明显圆形、会被拉变形就很怪的元素（小泡沫轻微变形可以）。
- 透明边缘干净，四周不留白边；左右两端自然收尖淡出，不需要无缝拼接。
- 画风干净、圆润、亮色，跟游戏整体一致；不要写实的水花、浪花或烟雾，**不要再画成云朵或卷浪**。

程序这边的用法（代码已写好，图交付后重新打图集即可生效）：

- 合成的玩具爆开时出现：正对合成的那一列，显示宽度约为屏幕的 55%。
