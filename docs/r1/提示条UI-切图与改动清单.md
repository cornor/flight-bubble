- 宽度按文字长度算（现在 toast 已经这样）。

### 2.2 图标

- 每条提示左侧放对应图标，高约条高 60%；替换代码画的警告三角（`WarnSign`）。
- 图标进图集后按 `ui/bar-icon-*` 取用；缺图时退回现在的画法。

### 2.3 装饰小泡泡（程序画）

- **样式**：透明玻璃泡，只有白色高光和淡边，不透明度 30–40%，颜色跟随边框；直径约条高 15–20%。
- **位置**：骑在边框线上，在右上角、左下角、右端三处里选一处；按文字内容固定选择（同一句每次同一处）；偶尔一大一小两颗。
- **数量**：

  | 类型 | 装饰泡泡 |
  |---|---|
  | 短消息（13–20、26） | 不加 |
  | 持续提示（01–03、05、07–11、27、29） | 最多 1 颗 |
  | 警告（04、06、17） | 不加 |
  | 庆祝（22、23、25、31–34） | 2–3 颗 |

- **动效**：提示条弹出时泡泡从边框冒出，轻轻上浮后停住。
