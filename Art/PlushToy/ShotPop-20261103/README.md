# 柔软开火 + 清脆破泡：第一版试听

2026-11-03。用户确认先制作一版，评估普通队员连续开火和泡泡消除的声音。这里是独立试听素材，尚未接入游戏；没有修改 Unity 代码、现有音效、音乐，也没有构建或发布。

## 试听

| 文件 | 内容 |
| --- | --- |
| `previews/01-single-ab.mp3` | 单个普通队员持续攻击，新旧对比，带当前关卡背景音乐 |
| `previews/02-full-ab.mp3` | 6 个普通队员持续攻击，新旧对比，带同一段音乐 |
| `previews/01-single-ab-dry.mp3` | 单队员对比，不带音乐 |
| `previews/02-full-ab-dry.mp3` | 6 队员对比，不带音乐 |
| `previews/03-new-variants.mp3` | 仅新版素材：0–5 秒依次 8 个开火声，5–10 秒依次 8 个消除声 |

前四段都是 **0–12 秒旧版 → 12–13 秒静音 → 13–25 秒新版**。每段旁边保留同名无损 WAV。

这里是离线模拟，**不是游戏实录**。旧版使用当前 `Audio/shot.ogg`、`Audio/hit.ogg`。新旧版的事件时间、音量、随机音高和背景音乐完全一致；只改变单发素材和新版的 8 个变体轮换。没有额外叠加连击、MAX 激光、炸弹或胜利提示声。

听感重点：开火是否有小动物用力吹气的感觉；击中是否有明确的破泡反馈；连续播放是否刺耳、像机械蜂鸣，或淹没音乐。技术检查不能替代主观试听，风格待用户确认。

## 这版的设计

- **开火**：56–65 毫秒，短气流加圆润的气压声，起音留 2–3 毫秒的缓冲。主体快速下落并收住，减少原版较明显的高频气声。
- **消除**：73–87 毫秒，短促破裂瞬态加中频空腔声，尾部快速衰减。给压力峰做轻微软饱和，保留清楚的起音，避免尖峰决定整段的音量。
- 每类 **8 个变体**。除音高外，长度、起音、衰减和噪声质感也有微小变化；打乱轮换，避免相邻重复。
- 相对旧版的每次事件能量控制在 **−0.2 至 +0.2 dB**。并未靠整体降低音量来制造对比；不同音色的主观响度仍可能不同。
- 无人声、混响、背景噪声或长尾。普通开火和击中的区别主要由音色及起音体现。

## 素材交付

- `masters/shot-01.wav` … `shot-08.wav`：24-bit PCM 原始开火素材。
- `masters/hit-01.wav` … `hit-08.wav`：24-bit PCM 原始消除素材。
- `delivery/shot/shot-01.wav` … `shot-08.wav`：16-bit PCM 开火交付。
- `delivery/hit/hit-01.wav` … `hit-08.wav`：16-bit PCM 消除交付。

单发素材都是 **44.1 kHz、单声道**。试听 MP3 是 192 kbps、双声道；单发居中，原有音乐保留双声道。试听使用 delivery 文件解码后的音频。

## 模拟与记录

`make_trial.py` 可复现整个目录的音频与记录，需要 Python 3、numpy 和 ffmpeg。它只向本目录写入。

- 以 60 fps、单队员发射间隔 `0.12 × 0.82 = 0.0984 s` 模拟持续有目标可打的普通攻击。命中延迟约 135–165 毫秒，只用于试音，未复刻关卡目标与弹道。
- 参考当前 `ChipAudio.Playback.cs` 和 `ChipAudio.Garden.cs`：开火最小间隔 70 ms；命中最小间隔 `80 + 30 × density` ms；density 每秒衰减 6；成功开火/命中分别增加 0.08/0.06；按当前公式计算播放音量；音高在 0.97–1.03 之间。
- 单队员每个 12 秒片段实际播放 111 次开火、111 次命中；6 队员片段播放 131 次开火、130 次命中。满卡槽并不会把所有声音叠在一起，因为现有游戏有全局声音频率限制。
- 音乐取当前 `Music/level.ogg` 的第 8–20 秒，沿用当前两个音乐声道合计的 0.52 增益。两版同起点、同音乐音量，不分别归一化或自动压低音乐。
- 所有试听使用同一个总增益 1.0，没有启用整段压限。
- `timelines.json` 保存每个实际播放事件的时间、种类、变体、音量、音高与密度。
- `manifest.json` 保存生成参数、文件哈希、时长、峰值、RMS、DC、频带能量、相对旧版单发能量差，以及 MP3 解码检查。

## 交付自查

生成 8 个开火变体及 8 个消除变体，哈希各不相同，试听轮换无相邻重复。单发原始波形首尾为零；交付和 MP3 解码后均没有达到满幅的样本。单发音量匹配、试听事件间隔与新旧共用节奏均已检查。引用的旧版开火、消除和音乐文件生成前后 SHA-256 一致。

本次仅完成技术验证与试听素材制作，尚未做真人听感验收，也未验证手机扬声器、微信 WebGL 中的实际播放效果。
