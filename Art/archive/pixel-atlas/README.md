# 原版游戏图集 PixelAtlas（已不在游戏里）

`PixelAtlas.fbtexture`（原位置 `UnityProject/Assets/Flightbeat/Resources/`，约 8 MB）是原版打飞机游戏的图集。

2026-11-05 用户决定清理：先打了一个不带它的测试包，与正式包在 9 个画面（教学关、第 3 关开局与战斗中、暂停、主页、主页设置、伙伴图鉴、胜利动画、胜利页）逐张截图对比，没有任何画面变化（缺图处会显示成白块，一处都没有），于是移到这里，正式包不再带它。下载量约少 0.3 MB，运行时少一张约 8 MB 的贴图。

没覆盖到的画面：复活页、失败页、大招、选关页。`PixelSurface.mainTexture` 在找不到它时会用白色贴图，所以万一还有地方用到，只会出现白块，不会崩溃。要恢复：移回原位置（Unity 会重新生成 .meta）。
