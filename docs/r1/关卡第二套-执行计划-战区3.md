## 2. 阶段 0：定题材（出图之前必须做完）

题材文档：`docs/r1/关卡第二套-题材-战区3.md`。里面已经放好每关的原关数据（颜色、底部构成、各色最低排、队员、补给），只差题材。

1. **起草**（Claude 或执行 AI）：照战区 1 的写法，每关写「题材 / 颜色怎么用 / 画面怎么放 / 说明」。
   - 先看原关数据：哪些颜色集中在底部、哪些只在上方，题材要让这些颜色自然落在对应高度（例：底部集中的颜色做地面、底座；只在上方的颜色做天空、帽子、月亮）。
   - 每种颜色都要有用途，不到 1% 的写成明确的小部件。
   - 位置写排号，并写「最下面 N 排以背景为主」（每排背景色 ≥90%，仍须保留少量其他颜色及其最低位置）；N 为 0 时不写纯背景底带。
   - 构图简单：一个主体加一两个道具。
2. **审查**：交另一个 AI 按战区 1 的两轮审查口径看一遍（颜色用途、位置是否和原关数据一致、有没有原关没有的颜色位置）。
3. **用户确认**：把总表发给用户，用户说可以才进入阶段 1。没确认不出图。
