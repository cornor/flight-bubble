## 0. 结论

- **目标**：版面布局不变，弱化背景、卡槽、排队区，让泡泡板成为画面里最突出的东西。
- **用户决定**：
  - 天空主题保留（蓝天、白云、右上角城堡和彩虹）。
  - 背景是图片素材，**重做背景图**比代码叠色更好：天空换色、浮岛云带淡化、两侧彩球去掉。
  - 下半区底色用**方案一（淡灰蓝，基本保持现状）**，不用暖奶白。
  - 顶部云带用 **A：保留但变薄**。
  - 空卡槽的金色漩涡**只留在“下一个队员落点”**，其余空位安静。
  - 排队的玻璃瓶换成**浅凹槽**，最前面能点的队员脚下加泡泡圈站台。
- **否决的做法**：
  - 第一版示意（降饱和 + 压暗 + 混灰）：画面发灰，像阴天（见 `01-初版-偏灰-已否决.png`）。
  - 泡泡板加有硬边的底板：违反 10-15 的决定“不要马赛克底板，珠子直接放在天空上”。
  - 直接删掉顶部云带：新泡泡会在一条硬边上凭空出现。
- **修订的旧决定**：UI 规范 v3 4.3（10-15）“空卡槽显示慢慢旋转的金色漩涡”，改为只在下一个落点显示。

## 1. 原则

1. **对比度分配**：泡泡板最强，UI 中等，背景最弱。用灰度截图检查，第一眼必须落在泡泡板上。
2. **颜色保持干净，靠明暗和色相拉开**：不要降饱和成灰色。薄荷绿、肉色泡泡偏亮，所以天空要更深一点，而不是更淡。
3. **减少细节，而不是加东西**：泡泡板周围不放会抢眼的形状和高光，也不加底板。
4. **不要和游戏元素长得像**：背景里不出现彩色圆球。

## 3. 程序改动

所有改动都在 `UnityProject/Assets/Flightbeat/Garden/PixelWingGame.Garden.cs` 的 `DrawGarden()` 里，不新增素材，不重建图集。

### 3.1 顶部云带（A：变薄）

- 现状：`Asset(s, "scene/ceiling", 0, 76, 540, 40, Color.white)`。
- 改为：`y = 88`，`h = 28`，tint 用 `new Color(1, 1, 1, .92f)`。
- **底边保持在 116**：泡泡只在 y ≥ 114 时才画，云带必须继续盖住这条生成线。

### 3.2 卡槽：只留下一个落点的漩涡

- 计算下一个落点：`Battle.Fleet.Count < Battle.UnlockedSlots` 时为 `nextBay = Battle.VisualSlot(Battle.Fleet.Count)`，否则 `nextBay = -1`。
- 底座绘制：
  - 有队员的卡槽、`nextBay`：照旧画 `scene/plot`。
  - 其余空的开放卡槽：`scene/plot` 改用 tint `new Color(.92f, .95f, 1f, .55f)`，半透明，融进灰蓝舞台。
  - 上锁卡槽不变。
- 漩涡和暖光（`Swirl` + `Glow`）：只画 `bay == nextBay` 的那一个。
- `PadUnlockFx`（广告解锁时的庆祝效果）不变。

### 3.3 排队区：玻璃瓶换成凹槽

- 删掉 `Asset9(s, "scene/queue-panel", x, 688, w, 180, …)` 及其兜底矩形。
- **凹槽**（每列一条，在屏幕坐标里画：先关掉 `MapLayout`，y 用 `ScreenLayout.Y()` 换算）：
  - 宽 `w × .86`，居中于 `Battle.QueuePositionX(lane)`；逻辑 y 694–866；两端圆头，半径约为宽度的 0.45。
  - 填充：深蓝 `(0.09, 0.2, 0.38)`，透明度 0.06。
  - 顶部内阴影：14 像素高，透明度从 0.10 渐变到 0。
  - 底部一圈 1 像素白色亮边，透明度 0.45。
  - 现有绘图函数里没有圆角矩形，需要新增一个辅助函数 `GrooveLane()`：圆头部分逐行画 `Rect`，中段用一个 `Rect`，每列约 60 个四边形。
- **前排站台**（该列有队员时才画）：
  - 中心 `(QueuePositionX, 727)`（逻辑坐标），宽 `58 × queueScale`，高 `18 × queueScale`。
  - 一层白色柔光（`Glow`，透明度 0.30），加一圈白色椭圆细线（透明度 0.55，用 `Segment` 连成折线）。
- **不变**：
  - 后两排已经是 76 对 82 的尺寸，并且在打瞌睡，不再另外缩小。
  - 教学提示光圈、合成金币、指定道具的角标、“已出战”标签都不变。
  - 泡泡炸弹瞄准时下半区的暗幕（656–874）不变。

### 3.4 本次不动

底部三个道具按钮、“点下方队员，开始出战”提示条、上锁卡槽和广告角标、顶栏 HUD、首页背景。
