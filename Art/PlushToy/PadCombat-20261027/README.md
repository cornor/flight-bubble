## 实现

- 每个角色一个三帧上半身图条：吸气抬头露胸口、撑盆探身吹气、柔软回弹。原始 PNG 在 `masters/<HEX>-combat-strip.png`。
- 原花盆从现有 idle 图直接取样，所有姿势使用相同的爪子落点。待机、排队、主页、耗尽继续使用原素材。
- 一个动作循环约 0.83 秒：吸气 0.20 秒，前冲 0.08 秒，持续吹气 0.40 秒，回弹 0.15 秒。每颗泡泡仍按实际战斗射速发射。
- 使用不透明关键帧和固定根部的柔软位移，避免交叉淡入时出现两双眼睛，也避免以嘴部强行变形造成脸部拉长。
- 每个姿势单独量取嘴部坐标；小象使用象鼻出口。粒子、子弹从当前姿势的嘴部位置衔接。
- 新动作的嘴边环随整口气发力；持续攻击底光降低到原效果的 30%，让身体动作能看清。命中爆泡的尺寸和触发逻辑沿用原设置。
- 现有真实射击音继续随射击事件播放，不按动画帧额外叠加声音。伤害、射速、弹药和关卡数据不在这轮修改范围。
- 42 张上半身按 224×224 登记进图集，角色图集扩大到 4096×4096，原角色分辨率继续保持 1.0。

## 评审与程序修正（2026-10-27 19:50，Claude）

用户反馈：攻击时玩具像拼接的，上下对不上。原因与处理：

1. **身子比花盆大**：上半身图只按高度登记，爪子横向跨度是花盆宽度的 1.4–1.75 倍。现按爪子所在行把身体等比缩放到花盆宽度的约 1.28 倍（`pad_combat_art.py` 计算 `fit` 写入 `pad-combat.json`；如小熊 0.73、水豚 0.82、猫 0.85、小象 0.92、小猪 0.82）。
2. **身子贴在盆沿前面**：改为先画身体、再从盆沿（y=146）画花盆盖在上面，身体从盆里探出来。代价：爪子下半被盆沿挡住，"扒盆沿"减弱。
3. **盆沿绿线**：原来花盆从待机图 y=124 截取，带进了叶子下半截；改为从 y=146 截，剩下的少量叶尖看起来像盆里的叶子。
4. **嘴边白圈挡脸**：有战斗图的队员不再画白圈，水珠和盆边气团保留。

## 待美术：战斗图第二版（批量前先改）

程序只能缓解，彻底解决需要按考拉 reach 第二版的做法，**把身体直接画进对应的花盆里**：

- 每帧用 `../PadReach-20261027/pot-plate-224x300.png` 同样的方法合成该队员自己的花盆（224×300，盆沿 y=192，花盆像素锁定）。
- 身体比例：连同爪子不宽于花盆的约 1.3 倍；躯干在花盆前沿后面（进盆里），两只小手压在盆沿**前面**。
- 保留待机图里盆沿两侧的叶子，切换待机/攻击时叶子不再出现、消失。
- 表情：吸气、回弹也要显得在使劲（水豚不要半闭眼的犯困感）；眼睛大小、脸型与该队员待机图一致，切换时脸不跳。
