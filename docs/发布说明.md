# 泡泡小队 WebGL 发布说明

本项目后续发布按以下规则执行。默认直接发布已经编译好的 WebGL 产物；只有用户明确要求编译时，才先编译再发布。每次成功发布后，提供本次改动概述和带版本参数的访问地址。

| 项目 | 配置 |
| --- | --- |
| 服务器 IP | `118.178.99.37` |
| 服务器站点目录 | `/www/wwwroot/minigame` |
| 项目目录名 | `paopao` |
| 当前线上目录 | `/www/wwwroot/minigame/paopao` |

| 本地 WebGL 产物目录 | `Builds/WebGL/GardenR1-bubble/`，相对仓库根目录 |
| 版本号 | 本次发布开始时的北京时间，格式 `YYYYMMDDHHmmss`，时区 `Asia/Shanghai`；同一秒重复发布时追加序号 |
| 访问地址格式 | `http://118.178.99.37/paopao/?v={version}` |

访问地址按站点根目录映射到 `/www/wwwroot/minigame` 约定；首次发布时核对服务器实际协议、端口和路径映射，并以验证通过的实际地址交付。版本号在同一次发布的记录、目录暂存名和交付链接中保持一致。

SSH 登录使用已有连接配置或用户提供的账号、端口和凭据；不在本文件保存密码或私钥。

## 是否编译

| 用户指令 | 执行方式 |
| --- | --- |
| “发布”“部署”“更新线上”“发布最新版本”等，没有明确要求编译 | 直接发布现有 WebGL 产物 |
| “编译并发布”“重新打包后发布”“构建后部署”等，明确要求编译 | 先执行构建，成功后发布新产物 |

直接发布时，不运行 Unity 构建、图集生成或其他会重新生成产物的步骤。即使源码或美术资源有新修改，也不自动编译；“最新”默认指现有的已编译产物。若产物缺失或不完整，说明具体问题并停止发布，等待补齐产物或用户明确要求编译。

仅在发布任务明确要求编译时，从仓库根目录执行：

```bash
bash scripts/r1v3/build.sh
```

该脚本会替换固定产物目录 `Builds/WebGL/GardenR1-bubble/`。编译失败则停止，不发布失败或残缺的输出。

## 发布步骤

1. 确认本次是否明确要求编译，并按上一节选择流程。检查产物中的 `index.html`、`Build/` 及页面引用的配套资源完整，确认没有构建进程正在改写该目录。
2. 生成本次版本号，记录产物时间、文件清单和校验值，准备相对上次成功发布的改动概述。发布记录保存在本地 `Builds/releases/{version}.json`，包含版本、发布时间、是否编译、产物路径、文件校验值、改动概述、最终地址和验证结果。
3. 将产物目录内的内容完整上传到 `/www/wwwroot/minigame/paopao.staging-{version}/`，校验上传结果。上线后的入口应为 `paopao/index.html`，不额外嵌套一层本地产物目录名。
4. 保留现在线上目录作为待回退版本，将完整暂存目录切换到 `paopao`。切换和验证期间，保留原有上一版备份，直到新版本验证通过。
5. 访问本次带版本参数的地址，检查入口及关键资源请求成功、WebGL 能正常加载进入游戏。首页的 `?v=` 用于标识发布版本；资源是否更新仍须核对实际资源 URL 和缓存行为。
6. 验证通过后，将本次替换下来的线上版本保留为 `paopao.prev`，删除更早的本项目发布备份、临时目录及上传包，并更新发布记录为成功。
7. 按下文格式报告本次改动概述、实际版本号和可点击的访问地址。

同一项目的发布应串行执行。上传或校验失败时不切换线上目录；切换后验证失败时恢复发布前的线上版本及备份关系，并报告失败情况。首次发布没有上一版时，不创建空备份。

## 目录保留规则

每次成功发布后，只保留当前线上版本和上一次成功发布的完整目录：

```text
/www/wwwroot/minigame/
├── paopao/       当前线上版本
└── paopao.prev/  上一次成功发布，用于回退
```

更早的发布目录不保留。清理范围仅限能够确认属于 `paopao` 的发布备份和临时文件，不清理站点目录下其他项目。旧备份在本次验证成功后再删除；发布过程中的临时保留不作为额外历史归档。

## 发布完成后的反馈

每次发布完成，必须给出本次实际发布内容的简要概述和带 `?v={version}` 的完整地址。版本号必须替换为本次实际值。

改动概述以产物对应的构建记录、产物差异和上次成功发布记录为依据。仅修改了源码但尚未编译进入产物的内容，不列为本次发布改动；不能确认具体功能变化时，说明“已发布现有 WebGL 产物，具体功能差异未确认”，并列出能够确认的产物变化。产物与上次一致时说明“重新发布相同产物，无内容变化”。

反馈格式：

```text
发布完成
版本：{version}
方式：直接发布现有 WebGL 产物 / 编译后发布（填写实际方式）

本次改动：
- {已确认的改动概述}

访问地址：http://118.178.99.37/paopao/?v={version}
备份：保留上一版 paopao.prev，更早版本已清理（首次发布则说明无上一版）
验证：{实际验证结果}
```

此处为反馈模板，首次实际发布后再生成发布记录。本文件建立于 2026 年 10 月 18 日。
